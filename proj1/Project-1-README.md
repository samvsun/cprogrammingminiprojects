## Project-1: Interactive Converter
## Interactive Menu Loop:
# Requirements
* Keep the program running inside a do-while loop until the user explicitly selects the Exit option.
* Clear the menu display for each iteration and print options clearly.
* Use switch case statements.
# Description
* The converter has four modes:
* Temperature Conversion: Celcius to Fahrenheit, Fahrenheit to Celcius, Celcius to Kelvin
* Distance Conversion: Kilometers to Miles, Miles to Kilometers
* Currency Conversion: INR to USD, USD to INR
* ADC Conversion (Temperature Sensor)
